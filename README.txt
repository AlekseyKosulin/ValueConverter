ValueConverter

Десктопное приложение для конвертации валют на C# Windows Forms с получением актуальных курсов через REST API.
Описание
Программа позволяет выбрать исходную и целевую валюту, ввести сумму и получить результат конвертации по текущему курсу из интернета.
Данные о валютах и курсах загружаются с бесплатного API Frankfurter.

Возможности

загрузка списка доступных валют при запуске;
конвертация суммы из одной валюты в другую;
проверка корректности введённой суммы;
обработка ошибок при отсутствии интернета или сбое API;
отображение результата с двумя знаками после запятой.

Используемые технологии
C# (.NET 10)
Windows Forms
HttpClient
REST API
async/await
